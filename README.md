功能说明
一句话
在 QQ 群里说「唱 歌名」，她会用指定音色把这首歌唱出来发给你；说「点歌 歌名」则直接放原曲。

支持的歌名写法

写法	效果
唱 晴天	按名字搜，多个版本让你选
唱 晴天 周杰伦版	指定歌手，支持模糊匹配（写「周杰伦」「周杰」「杰伦」都行）
唱 晴天 视频	后缀直接指定发送方式，跳过第三次询问
2. 点歌（点歌 / 听歌 / 放歌）
和翻唱同一套「选源 → 选版本」流程，最后直接发原曲：

时长 ≤ 120 秒 → 发语音
更长 → 发 mp3 文件
3. 三种发送方式
后台三个独立开关，只开一个就不问、直接按那个发：

开关	发出来是什么	说明
allow_voice	多条语音	单条上限 chunk_seconds（默认 120 秒），超过自动均分
allow_video	一条视频	封面 + 音频合成 mp4，一条消息听完，不是文件
allow_file	mp3 文件	时长不限

源	说明
网易云	默认源，搜歌 / 取直链 / 拿封面
B 站	网易云没有的歌（虚拟歌手、翻调、同人）基本都在这里
两个都开 → 每次问用哪个
只开一个 → 不问，直接用
版本列表会标 ［可听全］ / ［仅试听］ / ［B站］，并显示实际能拿到的时长
5. B 站扫码登录（管理员）
代码块


扫码登录     → 发二维码，B 站 App 扫，两分钟内有效
刷新状态     → 查当前登录是否还有效
重新登录     → 清掉旧 Cookie 再扫
登录后：音质更稳、少被风控；不会解锁会员音源。Cookie 约 30 天过期。

谁能用
开关	作用
owner_uins	谁是主人
owner_enabled	主人能不能点歌
others_enabled	其他人能不能点歌
admin_uins	管理员：无视触发词位置、无视唤醒、无视上面两个开关
trigger_words	只有以这些词开头的消息才算点歌（默认「唱歌」「唱」）
need_wake	关掉后触发词直接生效，不用 @
音质相关
参数	默认	调它会发生什么
diffusion_steps	60	越高越清晰越慢；高音发“砂”时调到 80
cfg_rate	0	贴合强度；调到 0.3–0.5 更像原唱音色，但高音更容易紧
semi_tone_shift	0	负值降调；能明显减少高音撕裂，但伴奏不会跟着变调
clip_seconds	420	最多唱多长（7 分钟）；歌更短就唱整首
混音链固定做了人声增强：高通 90Hz + 3kHz 提亮 2dB + 6.5kHz 压 2dB + 软压缩，人声 1.28 / 伴奏 0.55。

常见问题
Q：唱到高音破音？ 先确认不是削波（正常峰值在 −4 dB 左右）。如果还是“砂纸感”，按顺序试：diffusion_steps=80 → cfg_rate=0.3 → 换更长的参考音色（20–30 秒、含高音）。

Q：只唱了 30 秒就没了？ 那个版本是网易云 VIP 试听源。版本列表里会标 ［仅试听］，选别的 ［可听全］ 的版本。

Q：想一次听完一首歌？ 用「视频」发送方式，一条消息、点开就播，不受语音时长限制。

Q：第一次用很慢？ 首次会下 Seed-VC 权重（约 2.3 GB），之后每首都很快。

Q：纯 CPU 能跑吗？ 能，但一首 5 分钟的歌要十几分钟。
